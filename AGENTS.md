# Orientações do projeto

Este projeto é um dashboard didático para análise exploratória de vendas.

- Use HTML, CSS e JavaScript puro, Chart.js e Papa Parse por CDN com versões fixadas.
- Não use backend, banco de dados, React ou ferramentas de compilação.
- Mantenha o dashboard utilizável abrindo `public/index.html` diretamente; CSVs devem ser lidos localmente pelo seletor de arquivos.
- Preserve os arquivos de dados que já vieram com o projeto.
- Escreva a interface em português do Brasil, com contraste, navegação por teclado, layout responsivo e formatação brasileira.
- Valide os dados e explique descartes. Não remova duplicatas sem entender o significado das linhas.
- Documente indicadores, colunas, adaptações da base e instruções de publicação no README.
- Confira os cálculos e os fluxos principais solicitados; informe limitações de verificação.
